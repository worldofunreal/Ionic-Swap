# Ionic-Swap

**Unified DeFi interface with chain abstraction — swap any asset cross-chain gaslessly, without bridges or wrapped tokens.**

A [World of Unreal](https://github.com/worldofunreal) project.

## Stack

- **Frontend**: [Astro](https://astro.build) + Tailwind CSS (`src/`)
- **Backend**: Rust (`server/`)
- **Identity**: [WouID](https://github.com/worldofunreal/wou-id) (`@worldofunreal/id`) + Internet Identity (`@dfinity/auth-client`)

## Develop

```bash
npm install
npm run dev      # astro dev
npm run build    # astro build
npm run preview  # astro preview
```
